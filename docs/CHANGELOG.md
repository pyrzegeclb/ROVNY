# Changelog

## 0.2.0

Chat-first conversation workspace with per-project browser history, streaming responses, Markdown/code rendering, stop/retry/copy controls, chat/plan modes and editor expansion. Qwen3 14B default and longer local-model timeouts. Normal chat works without opening a project. Added chat API security, context budgeting and provider stream tests.

## 0.1.0

Initial local browser application: React/TypeScript UI, FastAPI backend, Ollama and OpenAI-compatible adapters, offline demo, reviewed file transactions, snapshots, project search, command runner and provider settings.

See `VALIDATION.md` for the checks actually performed on the delivered build.
