# Full project snapshot

This upload includes the complete local ROVNY project directory at the owner’s request: source, compiled frontend, logos, installed Python/Node dependencies, local provider settings, examples and recovery data. The original repository image and commit history are retained.

The bundled virtual environment and node_modules are a machine-specific snapshot. For a portable installation, follow README.md and reinstall dependencies. Gitignore remains in place to avoid accidentally adding new generated files; existing snapshot files are tracked explicitly.

Large Ollama model weights and the portable Ollama runtime live outside the project directory and are not included. Download a model using Ollama as described in the README. No tests were run for this upload; the commit requests GitHub Actions to skip automatic checks.
